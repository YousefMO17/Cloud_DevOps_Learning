Understand the Linux environment and identify basic system information.

## Commands Used

- cat /etc/os-release

- whoami
- hostname
- pwd
- git --version
- git status
- git branch --show-current

## What I Learned

Linux is technically a kernel.

A Linux distribution combines the Linux kernel with system utilities,
libraries, package management tools, and applications.

The Linux kernel manages hardware resources such as CPU, memory,
processes, storage, and networking.

I also verified that my Linux lab directory is tracked using Git
and worked on a dedicated Git branch.
