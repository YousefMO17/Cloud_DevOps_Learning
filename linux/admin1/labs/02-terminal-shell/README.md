# Lab 02 - Linux Terminal and Shell

## Objective

Practice the Linux terminal, shell, Bash, command structure,
tab completion, command history, and case sensitivity.

## What I Practiced

A terminal provides the interface used to interact with Linux.

A shell interprets the commands entered by the user.

Bash is one implementation of a Unix shell.

Linux commands commonly follow this structure:

command [options] [arguments]

Linux is case-sensitive.

Git repositories contain a hidden .git directory that can
be displayed using:

ls -a
