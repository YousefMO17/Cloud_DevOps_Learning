Lab: Standard Input, Output and Redirection

Standard Streams:

0 = stdin
1 = stdout
2 = stderr

Standard Output Test:

Command:
echo "Linux"

Output:

Linux

Overwrite Redirection Test:

Command:
echo "Linux" > report.txt

report.txt:

Linux

Command:
echo "Git" > report.txt

report.txt:

Git

Conclusion:

overwrites existing file contents.

Append Test:

Commands:

echo "Linux" > report.txt
echo "Git" >> report.txt
echo "GitHub" >> report.txt

Final report.txt:

Linux
Git
GitHub

Conclusion:

appends data without deleting existing contents.

stdout Redirection:

Command:
ls /etc > etc-files.txt

Result:
The normal output of ls was stored in etc-files.txt.

stderr Test:

Command:
ls /fake-directory

Result:
An error message was displayed because the directory does not exist.

stderr Redirection:

Command:
ls /fake-directory 2> errors.txt

Result:
The error was stored inside errors.txt instead of being displayed
as normal command output.

Separate stdout and stderr:

Command:

ls /etc /fake-directory > good-output.txt 2> error-output.txt

Result:

Normal output:
good-output.txt

Error output:
error-output.txt

Git History Redirection:

Git commit history was saved to git-history.txt.
